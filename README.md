# Digital Maze

[![Unity](https://img.shields.io/badge/Unity-2022.3.18f1-000000?logo=unity&logoColor=fff)](ProjectSettings/ProjectVersion.txt)
[![C#](https://img.shields.io/badge/C%23-239120?logo=csharp&logoColor=fff)](Assets/PixelArtTopDown-Basic/Script)

A 2D pixel-art maze game built in Unity. You explore a labyrinth guarded
by wandering monsters, and every locked door only opens once you solve a
quick mental-math problem (addition, subtraction, multiplication, or
division) generated on the spot. Get it right and the door opens; get it
wrong and you're stuck facing the monsters a little longer.

A fun, lighthearted student project rather than a serious simulation:
the goal was simply to build something playable and enjoyable to work
through.

## Gameplay

- Top-down movement through a hand-built maze, using a pixel-art asset
  pack as the visual base.
- Monsters patrol the maze and must be avoided.
- Locked doors present a randomly generated arithmetic problem; the
  correct answer unlocks the door.
- A tutorial level introduces the controls and the door mechanic before
  the main maze.

## Running it

Open the project in Unity 2022.3.18f1 (or later) via Unity Hub, then open
the `MainMenu` scene under `Assets/PixelArtTopDown-Basic/Scene/` and
press Play.
